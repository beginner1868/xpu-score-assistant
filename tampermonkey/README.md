# XPU成绩助手--Ryan_cy 油猴版

这是 Tampermonkey / 篡改猴 / Violentmonkey 的单文件脚本版本。

## 安装

在油猴中新建脚本，然后使用这个文件：

`C:\Users\Administrator\Desktop\查分插件\tampermonkey\xpu-score-assistant.user.js`

也可以直接把 `.user.js` 文件拖到浏览器里，让油猴识别安装。

## 使用

登录西安工程大学教务系统后打开成绩页面：

`https://jwglxt.xpu.edu.cn/student/for-std/grade/sheet/semester-index/你的内部ID`

脚本会自动在页面右侧显示成绩面板。
