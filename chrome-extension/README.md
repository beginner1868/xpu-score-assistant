# XPU成绩助手--Ryan_cy Chrome 扩展版

这是 Chrome / Edge 的“加载已解压扩展程序”版本。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择这个文件夹：
   `C:\Users\Administrator\Desktop\查分插件\chrome-extension`

## 使用

登录西安工程大学教务系统后打开成绩页面：

`https://jwglxt.xpu.edu.cn/student/for-std/grade/sheet/semester-index/你的内部ID`

页面右侧会显示成绩面板。关闭后可以点击右侧“成绩”按钮，或点击浏览器工具栏图标重新打开。

面板会直接展示总评、平时成绩、实验成绩、期末成绩，以及作业、课堂参与度、章节测验等成绩构成。
